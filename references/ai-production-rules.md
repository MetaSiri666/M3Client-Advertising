# AI 制作边界

## 全 AI 制作前提

这是全 AI 广告制作工作流。不要提出安排新的真人、场地或产品实拍。客户可以自由提供已经拥有的照片、视频、录音、产品图、界面、历史成片和参考图；这些素材可用于参考、合成、剪辑或一致性控制。

当 AI 难以稳定实现某个镜头时，优先采用：缩短镜头、拆分动作、改变景别、遮挡复杂部位、使用已有素材合成、后期添加文字与界面、风格化处理。不要把“重新实拍”作为默认解决方案。

## 真实性与权利

- 真实人物复刻、声音克隆和已有视频使用都需要客户拥有相应权利或授权。概念阶段可以基于客户提交材料预演，但正式制作前必须记录授权状态。
- 从公开网站读取的文字和图片默认用于研究理解。没有明确授权时，不直接把网站图片作为成片素材。
- 不虚构产品功能、性能数据、客户案例、销量、资质、荣誉、合作方、政府成果、科学结论或用户评价。
- 所有精确文字、数字、Logo、包装信息、界面、证书和官方标识优先使用客户源文件并在后期合成，不依赖图像模型直接生成。

## 常见制作风险

| 风险 | 处理方式 |
| --- | --- |
| 一张低清人物图要求跨镜头高保真 | 先做概念级预览，正式阶段请求多角度高清资料 |
| 多人物长时间口型同步 | 减少同时说话人数，拆成单人段落或旁白 |
| 复杂手部和精细产品交互 | 改变景别、拆动作或使用已有产品素材合成 |
| 长镜头连续变形 | 拆成短镜头，用匹配构图和后期转场连接 |
| 任何语言的精确文字、数字和需要准确复现的界面 | 生成阶段留出干净区域，后期叠加 |
| 同一角色或产品跨镜头一致 | 锁定参考、服装、视角、光线与场景，并预留筛选成本 |
| 医疗、金融、教育或公共政策表述 | 只使用客户提供或可核实的正式来源，列入审核项 |

## 内部封装

生成 Hero Shots 时必须同步建立内部制作包，记录逐镜头图像提示词、视频化动作、负面约束、参考图绑定、角色设定、镜头连续性和后期合成清单。内部包保存为单独文件，不粘贴进客户对话。只有内部制作人员明确请求时才展示或导出。
